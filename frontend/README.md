# Фронтенд

Статические HTML/CSS/JavaScript без сборщика и стороннего UI-фреймворка:

- `index.html` — оболочка приложения;
- `app.js` — регистрация, вход, видеостена и администрирование;
- `player.js` — воспроизведение сжатого fragmented MP4 через MediaSource или ManagedMediaSource, ограниченные очереди и очистка видео при переключении. При восстановлении сохраняется последний кадр в памяти canvas с явной отметкой; отдельные снимки и видео не записываются на сервер;
- `style.css` — оформление и адаптив;
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA.

Файлы обслуживаются бэкендом по явному списку. Публичные URL `/app.js`, `/style.css`, `/sw.js` и `/icon-192.png` сохраняются независимо от расположения файлов в репозитории. Service worker остаётся в корне URL, чтобы область PWA охватывала всё приложение.

API и WebSocket используют тот же origin. Для входа и эфира нужен сервер: открывать index.html через file:// не следует. Service worker кэширует только публичную оболочку, никогда API, кадры или данные пользователя. Для установки на телефон нужен доверенный HTTPS.

Кнопка увеличения разворачивает существующее видео на весь экран без модального окна и дополнительного плеера. Для мобильных заданы muted/defaultMuted/playsInline и отключены штатные контролы; видео не скрывается до старта, чтобы не мешать политике WebKit. Если браузер запрещает автоматический запуск, одно общее касание запускает все ожидающие камеры. В обычном режиме дополнительная кнопка не показывается.
