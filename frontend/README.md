# Фронтенд

В установленной PWA жест вниз от начала страницы обновляет приложение без подсказок и дополнительных кнопок. Короткое движение, горизонтальный жест, прокрутка вложенного списка и жест в полноэкранной камере обновление не запускают. Перед перезагрузкой сохраняются ожидающие изменения видеостены.

Статические HTML/CSS/JavaScript без сборщика и стороннего UI-фреймворка:

- `index.html` — оболочка приложения;
- `app.js` — регистрация, вход, видеостена и навигация;
- `admin.js` — списки разделов и объектов, редакторы и поиск доступов;
- `audio.js` — включение звука одной камеры через WebAudio; G.711 декодируется в браузере, без дополнительного подключения к регистратору;
- `player.js` — воспроизведение сжатого fragmented MP4 через MediaSource или ManagedMediaSource, ограниченные очереди и очистка видео при переключении. При восстановлении сохраняется последний кадр в памяти canvas с явной отметкой; отдельные снимки и видео не записываются на сервер;
- `style.css` — оформление и адаптив;
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA.

Файлы обслуживаются бэкендом по явному списку. Публичные URL `/app.js`, `/style.css`, `/sw.js` и `/icon-192.png` сохраняются независимо от расположения файлов в репозитории. Service worker остаётся в корне URL, чтобы область PWA охватывала всё приложение.

API и WebSocket используют тот же origin. Для входа и эфира нужен сервер: открывать index.html через file:// не следует. Service worker кэширует только публичную оболочку, никогда API, кадры или данные пользователя. Для установки на телефон нужен доверенный HTTPS.

Админка использует адреса вида `#/admin/users/2`. «Управление» сразу открывает пользователей. На телефоне разделы доступны через кнопку меню, на компьютере — в постоянном боковом меню. Изменения сохраняются кнопкой в закреплённой шапке; при уходе с изменённой формы запрашивается подтверждение. Черновики остаются только в памяти страницы. Камеры и группы выбираются отдельным списком с поиском и счётчиком; «Назад» браузера возвращает в редактор. Сохранённые параметры подключения в форму не загружаются; вместо них показаны имя регистратора, число каналов и результат проверки подключения. Приглашение после создания показывается в диалоге: ссылка и кнопка рядом копируют её. Отзыв доступен прямо в списке, названия камер редактируются на месте.

Новая плитка появляется только после выбора камеры. Сетки выбираются одним нажатием; произвольное число колонок доступно в «Настроить». [Браузерная проверка мобильных сценариев](../tests/frontend/README.md).

Кнопка увеличения разворачивает существующее видео на весь экран без модального окна и дополнительного плеера. Для мобильных заданы muted/defaultMuted/playsInline и отключены штатные контролы; видео не скрывается до старта, чтобы не мешать политике WebKit. Если браузер запрещает автоматический запуск, одно общее касание запускает все ожидающие камеры. В обычном режиме дополнительная кнопка не показывается.
