# Домовые камеры

Веб-приложение для совместного просмотра камер: прямой эфир, личная видеостена и доступ по приглашениям. Работает в браузере компьютера и телефона; на телефоне устанавливается как PWA.

## Какие камеры можно подключить

Поддерживается подключение к видеорегистратору через **облачную платформу XMEye / Xiongmai** — удалённый доступ по серийному номеру (Cloud ID). Камеры просматриваются как каналы этого регистратора. Один экземпляр приложения подключается к одному регистратору.

Первый признак совместимости — удалённый просмотр регистратора в XMEye. Нужны Cloud ID, логин и пароль самого регистратора. Учётная запись в облачном приложении их не заменяет. Параметры вводит администратор в разделе «Управление → Подключение».

Используется протокол DVRIP. Успешный просмотр в XMEye помогает определить платформу, но совместимость прошивки проверяется подключением. Наличие P2P у устройства другой облачной платформы совместимость не гарантирует.

Видео передаётся в исходном формате H.264 или H.265 без серверного перекодирования. Для просмотра браузер и устройство должны поддерживать кодек потока, особенно H.265.

## Возможности

- Личная видеостена до 64 экранов с автоматическим сохранением сетки, порядка и размеров; полноэкранный просмотр отдельной камеры.
- Пользователи видят разрешённые камеры; администраторы управляют пользователями, доступом, блокировкой, группами и названиями камер.
- Одноразовые приглашения с заранее назначенными ролью и доступом.
- Постоянное подключение камер группы «Все камеры»: зрители получают общий поток. Состав группы редактируется.
- Установка на телефон через HTTPS. Для прямого эфира требуется сеть.

## С чего начать

Разверните приложение по [инструкции для сервера](deployment/README.md) или подготовьте [локальное окружение](scripts/dev/README.md). При первом открытии создайте администратора, настройте подключение и пригласите пользователей. Готовых паролей нет.
