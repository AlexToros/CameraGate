# Домовые камеры

Веб-приложение для совместного просмотра камер: прямой эфир, личная видеостена и доступ по приглашениям. Работает в браузере компьютера и телефона; на телефоне устанавливается как PWA.

## Какие камеры можно подключить

Поддерживаются камеры, подключённые к видеорегистратору с удалённым доступом через **облачную платформу XMEye / Xiongmai**. Для подключения нужны три параметра регистратора: Cloud ID (серийный номер), логин и пароль.

Если вы уже смотрите камеры через одно из приложений или сервисов ниже, это решение можно использовать вместо него для просмотра прямого эфира с совместимого регистратора:

- [XMEye](https://download.level1.com/level1/manual/XMEye%20APP%20User%20manual.pdf) — мобильный клиент с добавлением устройства по серийному номеру, логину и паролю.
- [XMEye Pro](https://www.hiseeu.com/a/help/article/41795) — мобильный клиент с теми же параметрами при ручном добавлении устройства.
- [VestaCloud](https://t54.ru/downloads/Mobilnoe_prilozhenie.pdf) — мобильный клиент для устройств VeSta с подключением по облачному серийному номеру.
- [xmeye.net](https://www.xmeye.net/en/) — веб-портал с подключением по серийному номеру, логину и паролю в режиме By Device.

Список помогает определить платформу, но совместимость конкретной прошивки проверяется подключением. Наличие Cloud ID или функции P2P у устройства другой облачной платформы совместимость не гарантирует. Один экземпляр приложения подключается к одному регистратору и показывает его каналы.

Видео передаётся в исходном формате H.264 или H.265 без серверного перекодирования. Для просмотра браузер и устройство должны поддерживать кодек потока, особенно H.265.

## Возможности

- Личная видеостена до 64 экранов с автоматическим сохранением сетки, порядка и размеров; полноэкранный просмотр отдельной камеры.
- Пользователи видят разрешённые камеры; администраторы управляют пользователями, доступом, блокировкой, группами и названиями камер.
- Одноразовые приглашения с заранее назначенными ролью и доступом.
- Постоянное подключение камер группы «Все камеры»: зрители получают общий поток. Состав группы редактируется.
- Установка на телефон через HTTPS. Для прямого эфира требуется сеть.

## С чего начать

Разверните приложение по [инструкции для сервера](deployment/README.md) или подготовьте [локальное окружение](scripts/dev/README.md). При первом открытии создайте администратора, настройте подключение и пригласите пользователей.
